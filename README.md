# Agentix — AI Agents Working 24/7

A production-ready React + Tailwind CSS web application built from the Figma design for **Agentix**, an enterprise platform for deploying autonomous AI agents that handle operations, sales, support, and workflows 24/7.

## 🚀 Features

- **7 Complete Pages**:
  - **Home**: Hero section, interactive Agent Performance analytics chart, Bento feature grid, 3-step onboarding workflow, monthly/annual pricing calculator, testimonials, FAQ accordion, and global CTA.
  - **Blog**: Category filtering, featured highlight article, and 9-card post grid.
  - **Article / Blog Details**: Full-length editorial typography, breadcrumbs, author bios, inline graphics, and related articles.
  - **Contact**: Multi-channel support cards, responsive contact form, and social proof metrics.
  - **Terms & Conditions**: 10 comprehensive legal policy sections.
  - **Privacy Policy**: Data security, compliance, cookies, and privacy disclosures.
  - **404 Page**: Custom illustrated monster graphic with seamless navigation back to home.
- **Interactive Modals**: "Book a Demo" modal with full form validation and confirmation states.
- **Responsive Design**: Designed for high-fidelity desktop and fully adapted for tablets and mobile devices with collapsible navigation.

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Icons)

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized bundle will be created in the `dist/` directory.
